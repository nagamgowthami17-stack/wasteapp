
# 🌿 GreenVision – AI-Based Smart Waste Classification System

## About the Project
GreenVision is an AI-powered waste classification system developed using Python and Streamlit. It uses machine learning to identify different types of waste from uploaded images and provides disposal recommendations.

## Features
- AI-based waste image classification
- Supports 12 waste categories
- Image preview
- Top 3 AI predictions
- Prediction confidence score
- Waste disposal recommendations
- Admin dashboard with statistics
- Classification history
- CSV report downloads

## Technologies Used
- Python 3.11
- Streamlit
- PyTorch
- Hugging Face Transformers
- Pandas
- Pillow

## Supported Waste Categories
1. Battery
2. Biological
3. Brown Glass
4. Cardboard
5. Clothes
6. Green Glass
7. Metal
8. Paper
9. Plastic
10. Shoes
11. Trash
12. White Glass

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## AI Model
Hugging Face model: watersplash/waste-classification
